# 指针矩阵性能检查

2026-10-16，在同一个 Chrome 窗口、相同的首次排字动画（09:41）中测量：

| 指标 | 原 DOM 指针 | Canvas 2D |
| --- | ---: | ---: |
| 动画帧率 | 5 FPS | 59 FPS |
| 帧间隔 P95 | 366 ms | 17.6 ms |
| JS 绘制平均耗时 | 0.675 ms | 0.157 ms |
| 每帧指针样式写入 | 432 | 0 |

原版每帧为 432 根 DOM 指针写入 transform，且指针、表盘使用阴影。测得 JS 计算时间远小于帧间隔，主要瓶颈在大量 DOM 变更后的渲染链路，而非角度计算。

现在使用单个 Canvas；表盘与材质只在尺寸变化时绘制到底图缓存。每帧复制缓存底图，用一条批量路径绘制全部指针；用类型化数组保存角度和坐标，不再创建逐帧数组与变换字符串。动画结束后停止 requestAnimationFrame，切到后台暂停绘制，像素比上限 2。

双线字形、216 个表盘、双指针独立角度、联动编排和三秒演示均保留。具体测量值见 performance-before.json 与 performance-after.json；这是当前浏览器和窗口下的单次测量。
