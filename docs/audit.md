# 时钟合并与检查

日期：2026-10-16。最终集合为 7 款。

| 编号 | 时钟 | 处理与校验 |
| --- | --- | --- |
| 01 | 指针矩阵 | 默认秒数，360 表盘；三秒归位校验整齐起点、1500ms 中间态及 3000ms 正确终点。 |
| 02 | 整位滑轨 | 固定遮罩预计算与生成器结果一致；86,400 种读数；Focus 为 50% 视窗宽度。 |
| 03 | 原作双轨 | 作者 STL 与 Arduino 位置表，86,400 种读数；Focus 为 50%。 |
| 04 | 字母滑轨 | 53 字符、2,809 个有序过渡、六字位轮播和输入；Focus 支持时间及文字模式。 |
| 05 | 数字矩阵 | 原版样式与 CSS SHA-256 保持一致，统一时间源及窗口缩放。 |
| 06 | 中文文字时钟 | 固定中文、66 格，保留原版主题、精度与读秒。 |
| 07 | 英文文字时钟 | 固定英文、264 格，与中文共用原版实现，保留主题、精度与读秒。 |

08 运动表、09 彩色时钟、10 十六进制时钟、11 滚动时钟已从页面、目录、缩略图及相关实现中移除。colorful_time_plug_in 原仓库保持原状。

## 验证

- `npm run check`：数字边界、全天时间、共享虚拟 Date、原版 CSS SHA-256、四款滑轨几何与七页 DOM 执行。
- 共享时间源：演示 3,000ms 前进 60,000ms，验证 23:59 到次日 00:00。
- Chrome：目录筛选、实时/演示、前后切换、全屏、滑轨设置与秒数开关、字母输入；恢复后的 06、07 重新检查主题、菜单与手机尺寸。
- 原视频存在透视与遮挡，仅复刻外观与动作原理，不声称精确复现硬件全部编排。

记录见 dom-check.json、browser-check.json、restored-styles.json 与 performance.md。缩略图为实际网页截图；浏览器扩展浮层偶尔可能出现在截图边缘。

当前版本的手机三尺寸检查、Focus 几何与加载说明见 [v2.3.0](v2.3.0/README.md)。分列滑轨仅保留历史实现用于旧回归夹具，目录及旧集合链接统一进入整位滑轨。
