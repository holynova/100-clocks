# 时钟合并与检查

| 编号 | 时钟 | 处理与校验 |
| --- | --- | --- |
| 01 | 指针矩阵 | 双线边界字形；每个边界枢轴恰好两条边。检查 10 个数字、1,440 个分钟。DOM 逐帧变更是卡顿瓶颈，改为缓存底图与单 Canvas，当前 Chrome 实测 5→59 FPS。 |

| 06 | 数字矩阵 | 恢复原版 Matrix Clock Ultra，原始 CSS 不变；仅接入统一时间源和缩放适配，避免同一秒反复更新网格。 |
| 07 | 文字时钟 | 恢复原版 Word Clock，原始 CSS、精度、主题与网格不变；仅接入时间源，修复英文读秒变量与分钟变量重名。 |

## 验证

- `npm run check`：数字边界、全天时间、共享虚拟 Date、原版 CSS SHA-256、四款滑轨几何与七页 DOM 执行。
- 共享时间源：演示 3,000ms 前进 60,000ms，验证 23:59 到次日 00:00。
- Chrome：目录筛选、实时/演示、前后切换、全屏、滑轨设置与秒数开关、字母输入；恢复后的 06、07 重新检查主题、菜单与手机尺寸。
- 原视频存在透视与遮挡，仅复刻外观与动作原理，不声称精确复现硬件全部编排。

记录见 dom-check.json、browser-check.json、restored-styles.json 与 performance.md。缩略图为实际网页截图；浏览器扩展浮层偶尔可能出现在截图边缘。
