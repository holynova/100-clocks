# 物质与光学系列 · v3.0.0

根据「网页时钟灵感参考」聊天里优先推荐的四个方向，新增 08–11。原有七款保留；此前删除的旧案例没有恢复。四款使用原生 Canvas 2D、统一时间源、统一设置面板，无新增运行时依赖。

| 案例 | 网页实现 | 可操作项 |
| --- | --- | --- |
| 08 机器人写字 | 两组固定长度连杆通过逆运动学追踪笔尖；先擦除，再按原创数字路径书写。每分钟启动一次。 | 重新书写、笔墨颜色、机械臂显隐；轻触或 Enter 重写。 |
| 09 磁流体时钟 | 径向粒子场叠加、阈值显形，弹簧与阻尼把液滴聚向数字。 | 秒数、颜色、触摸磁场、扰动后重组。 |
| 10 莫尔纹时钟 | 背面光栅在数字内部错开半个周期；前面光栅平移，让两层实际叠加产生显影、消隐和反相。 | 光栅状态、密度、秒针、拖动与重新显影。 |
| 11 数字沙漏 | 细粒在重力下落入数字字模；换分时旧粒坍塌，新粒重新沉积。 | 秒数、沙色、落沙速度、坍塌重组；轻触或 Enter 重播。 |

四款是对原作概念的原创网页演绎。机器人不是硬件尺寸精确的制造模型，磁流体是视觉粒子场而非真实流体求解；莫尔纹是线性光栅变体，没有复制 STATION 的旋转纸盘图案；数字沙漏采用数字字模，并非原硬件 LED 沙漏的复制。数字路径及绘制代码在本仓库独立编写。

## 灵感来源

- [9a / Plotclock](https://github.com/9a/plotclock)：双机械臂白板写字时钟，阅读项目说明及 Arduino 原作以理解运动方式。
- [Zelf Koelman / Ferrolic](https://thekidshouldseethis.com/post/ferrolic-a-ferrofluid-clock-prototype-by-zelf-koelman)：磁流体聚合为时间的视觉概念。
- [STATION Design / Moiré Clock](https://stationdesign.co/moire-clock)：Felix Cooper、Amber Li 的光学显影时钟。
- [PanduTechLab / Sand Clock](https://github.com/PanduTechLab/Sand-Clock-)：重力沙漏的硬件时钟概念。

设置面板内的「查看原作」直达相应来源，没有导入原作媒体或运行代码。

## 验证

- `npm run check`：21 项单元测试；含双臂可达性、连杆长度、光栅相位覆盖率、沙粒可复现性、静止后停止绘制、四款减少动态效果偏好、午夜更新。另有 11 款 DOM 运行、原版 CSS 哈希及滑轨全日 86,400 个读数回归。
- Chrome 实际检查：四款桌面与手机画面、统一选项、换墨重写、流体秒数/颜色/扰动、光栅反相/密度/秒针、沙粒换色/坍塌。机器人演示通过 23:59:58 跨到次日。
- 尺寸检查：320×568、375×812、812×375；横竖屏均无横向页面溢出，画布与说明在视窗内。机器可读边界记录见 [experiments-responsive.json](experiments-responsive.json)。
- 流体场在 500×250 低分辨率场中计算，上屏插值，最高 30 帧；画布像素比最高 1.75。书写和沙粒静止后停止动画帧，后台停止绘制。减少动态效果偏好和缩略图模式直接显示静态时间。
- 缩略图来自真实网页在 960×600 下的渲染；截图在 [screenshots](screenshots/)。
