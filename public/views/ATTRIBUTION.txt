This page adapts the perforation geometry of L1–L4 and R1–R3, the 0–9 position tables from timeslider.ino, and the visible fixed grid/guard layout. Those adaptations are shared under the same CC BY-NC-SA 4.0 license. We added a six-digit seconds display, responsive SVG rendering, web animation, themes and testing controls. This is a web interpretation, not the original Arduino program or a dimensionally exact manufacturing model.
